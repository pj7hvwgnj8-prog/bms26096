# Shreeya Singh — IIS Portfolio

This is a simple portfolio website for Shreeya Singh, Section B, for IIS projects.

## Files

- `index.html` — the website content
- `style.css` — the website design
- `cv.pdf` — add your CV here when ready
- `projects/` — optional folder for project files

## Adding your CV

Put your CV PDF in this folder and name it exactly:

`cv.pdf`

## Adding a project

Open `index.html` and copy an existing `<article class="project-card">...</article>` block.

Change:
- project number
- project title
- description
- status

When you have a PDF/PPT/project link, I can show you exactly where to put it.

## Netlify

After the GitHub repository is connected to Netlify, every push to the selected GitHub branch can automatically redeploy the website.
